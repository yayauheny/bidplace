# Target solution

Эталонные визуальные решения Bidplace. Эта папка содержит утверждаемые screenshots, к которым должна стремиться реализация.

## Правила

- Изображения в этой папке — визуальный source of truth для review.
- Production-код не считается изменённым автоматически после обновления Pen.
- Каждая картинка именуется по route, viewport и state.
- Новые варианты добавляются только после согласования.

## Current baseline

- `bidplace-youthful.pen` — отдельное новое направление, старый `bidplace-web.pen` не изменяется.
- Catalog: desktop / tablet / mobile — rounded youthful direction.
- Product detail: desktop / tablet / mobile — default.
- Public seller: desktop / tablet / mobile — default.
- Admin moderation: desktop / tablet / mobile — default.
- Login and register: desktop / tablet / mobile — default.

## Visual direction

- Reference: `https://myplastic.app/`.
- Warm off-white canvas, charcoal typography, coral accent.
- Rounded product media wrappers, pill controls, soft cards, compact mobile bottom navigation.
- Seed product photography is used only as documented development reference.

## Open differences

- Некоторые текущие Pen-кадры являются рабочими черновиками и могут отличаться от целевого решения.
- States loading, empty, error, permissions and long-content должны быть добавлены в эту папку после отдельного review.
- Финальное решение по primary button color и брендовым assets остаётся за founder acceptance.
