# MyPlastic / Plastic — visual source overview

Status: **primary visual and interaction source for selected bidplace patterns**

Official website: [myplastic.app](https://myplastic.app/)
Visual evidence: locally saved mobile screenshots supplied to this project; checked 2026-07-27.

MyPlastic is a reference for visual grammar—not a feature blueprint. Take its calm editorial hierarchy, mono utility labels, rounded black actions, sheets, restrained controls, and image-first composition. Do not inherit its vinyl imagery, scanning, Discogs integration, subscription model, or collection semantics.
