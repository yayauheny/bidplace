# Вопросы основателю

Принятые C1–C16 и DEC-152 не переоткрываются. Расхождения старой фиксации встречи с COMMERCE в черновик не вернулись: нет обязанности выкупить без права отказа, нет запрета отметить отказ автора, нет полей доставки до ставки, нет автоматической передачи следующему участнику, WhatsApp не добавлен к контактам.

## 1. Срок хранения данных о сделках

Не выбран. Заказы, ставки и жалобы участники не удаляют. Это продуктовое правило, не срок хранения.

30 дней в действующей политике — срок ответа и удаления из рабочих систем по запросу субъекта. Он не равен сроку хранения заказов, ставок, жалоб, страйков и сигналов. Черновик политики оставляет единственную пометку `[ЮРИСТ: срок хранения]` и не подставляет 30 дней.

## 2. Фраза об аналитике

DEC-150 принял риск личного сбора аналитики с запуска и не дал текста основания. Действующая политика всё ещё содержит квадратную пометку. Пока такая пометка есть в опубликованном пакете, API отвечает 503 и документы не отдаёт. Черновик основание не сочиняет. Нужна фраза для публикации либо решение оставить пакет закрытым.

## 3. Куда писать согласие на контакты контрагента

Рекомендация в [amendments.md](amendments.md): не добавлять это в регистрационную галочку, а принять вместе с Правилами сделок и одной граничной фразой в согласии на обработку. Если носитель должен быть другим, черновик в `site/` не переносить.
