## Три слоя в каждом файле

1. **Действует в MVP.** Страницы работ для портфолио; аукцион; прямая продажа по
   фиксированной цене с опциональным предложением цены. Оплата и доставка идут напрямую
   между сторонами. Контакт открывается после результа. Доступ 18+; история торгов и сделок сохраняется.
2. **В следующей редакции.** Чат, подписка, продвижение, отзывы, дропы,
   рассылка и другие будущие функции не входят в публичные тексты MVP. Перед их
   включением нужна новая версия связанных документов.
3. **Не в этой редакции.** Касса за вещь, эскроу, курьер площадки, паспорт KYC, крипта. Если появится (~1000 сделок в месяц и другая юрисдикция) — новый пакет документов, не дописка абзаца.

В интерфейсе кнопок «скоро» нет. В тексте абзац слоя 2 уже есть: при запуске чата меняем продукт, не набор бумаг.

## Плейсхолдеры до ИП

Пока в текстах скобки, не чужое имя и не выдуманный УНП.

| Поле | Сейчас |
|---|---|
| Оператор | ИП [наименование], УНП [номер], адрес [адрес] |
| Право | Республика Беларусь |
| Почта | support@bidplace.com |
| Сайт | [домен] |
| Хостинг / место баз | [указать при публикации] |
| Версия документа | draft-2026-08-30 |
| Срок хранения переписки чата | [указать при включении чата] |

Закрытый тест без рекламы с улицы и без денег на личный счёт физлица — без публикации этих текстов как оферты. Публичный запуск, реклама, живые авторы не из круга друзей, деньги за подписку — сначала ИП, потом подставить реквизиты и выложить.

## Галочки в продукте

Простыню в форму не класть. Короткая фраза, синяя ссылка на страницу документа.

| Где | Что |
|---|---|
| Регистрация | Структура acceptance и отдельных согласий открыта до ответа юриста. Политика не считается договором сама по себе; 18+ показывается отдельно. |
| Cookie | До ответа юриста — только технически необходимые cookies; аналитика и реклама не включаются заранее. |
| Ставка, fixed buy, offer | У каждого действия разные последствия. Момент и форма подтверждения определяются отдельно по письменному ответу. |
| Заявка автора | Ссылка на правила для авторов и на запрещённое. |
| Перед публикацией работы | Красная плашка: не сниму только потому, что цена не понравилась. |
| Если появится рассылка | Отдельная галочка. Код с почты и «вы победили» — не маркетинг, они уже в оферте. |

Площадка сохраняет версию документа и время принятия.

## Чат (слой 2, в оферте и политике уже)

- инструмент, не сторона переписки, не гарантия доставки сообщения;
- нельзя прятать за подписку чтение сообщений победителя или автора по сделке;
- запреты как в правилах поведения; модерация, бан, жалоба;
- хранение для споров — срок плейсхолдер;
- контакт в Telegram / телефон чат не отменяет;
- передача ПДн в чате — только в рамках сделки / функции, дублировать в политике и согласии.

Пока чата нет: после продажи победителю уходит контакт автора, стороны пишут сами.

## Не копировать с bidbaits

Оператор РФ и только 152-ФЗ. «Пользуешься сайтом = согласился». Снять работу когда угодно, даже со ставками. Корзина, автоставки, анонимный аукцион. «Мы вообще не посредник». 48 часов связи как закон площадки. Чужие ФИО и ИНН.
