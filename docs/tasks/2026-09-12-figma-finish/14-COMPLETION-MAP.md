## 4. Критерии готовности

Задача считается закрытой, когда выполнены оба gate и обновлены статусы.

Visual accepted:
1. Для каждого элемента из таблиц §3 есть пара «Figma reference / runtime» при 390 px, масштабе 100 %, одинаковом scroll и, где возможно, одинаковом фото; расхождение геометрии ≤ 1 px, различия сглаживания шрифта объяснены отдельно.
2. Проверены 1024 и 1440 px: центрированная колонка 390, `document.scrollWidth === innerWidth`.
3. Проверены применимые состояния: loading, empty/optional, error + retry, missing media, длинные данные.
4. Keyboard/focus для tabs, кнопок, галереи и modal; Back/Forward между страницами без reload; reduced motion; последний контент доступен под dock.
5. Файлы в `artifacts/figma-qa/<task-id>/` и `REPORT.md` со ссылками на них и на source nodes.

Technical pass:
1. `pnpm --filter @bidplace/mobile typecheck`, ESLint изменённых файлов без auto-fix, `vitest run` для затронутых spec, `expo export --platform web`.
2. Новые тесты — только на изменённую логику (не на CSS-константы).
3. Diff не содержит `.pen`, Figma exports, API-контрактов, seed, `.env`.

Документация: `docs/design/04-DESIGN-STATUS.md`, `docs/product/11-PROJECT-STATUS.md`; при изменении shared токенов/masters — `docs/design/03-DESIGN-SYSTEM.md`. Статус экрана `Implemented` только после закрытия всех строк §3 для него; иначе `Partial` с перечислением оставшихся строк.
