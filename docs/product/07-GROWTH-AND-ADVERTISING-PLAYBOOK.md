# bidplace — реклама и развитие спроса

Последнее обновление: 2026-07-18  
Статус: Planned

## 1. Принцип

Реклама не продаёт «ещё один marketplace».

Она показывает:

- человека;
- предмет;
- историю;
- ограниченность;
- дату;
- честную прямую продажу.

Основная тема: **ценность**.

## 2. Воронка

```text
история человека
→ история предмета
→ preview
→ правила
→ ставка/покупка
→ передача
→ кейс
→ доверие к следующему creator
```

Сначала аудитория приходит к человеку. Платформа переносит часть доверия на bidplace.

## 3. Запрещено

- fake bids;
- fake views;
- fake buyers;
- ложный countdown;
- fake sold out;
- накрученные comments;
- hidden ads;
- обещание инвестроста;
- spam;
- частые бессмысленные email;
- mass targeting без лота.

## 4. Этап 0: technical

Цель: не traffic, а product check.

- сайт не афишируется;
- test lot явно test;
- direct links;
- no public ads;
- bug collection.

Метрики только технические.

## 5. Этап 1: первый creator

Кандидат: Таисия.

bidplace помогает:

- выбрать работу;
- сформулировать value;
- подготовить фото;
- написать историю;
- установить price;
- создать preview;
- подготовить announcement;
- tracking.

Материалы:

1. main image;
2. branded story;
3. short copy;
4. start;
5. end;
6. start price;
7. link;
8. one-screen instructions.

Пример:

```text
Работа: ...
Автор: ...
Почему важна: ...
Аукцион: ...
Начальная цена: ...
Участие: ...
```

Каналы:

- автор;
- bidplace;
- personal repost;
- Telegram;
- limited paid social.

Бюджет:

- сумма, которую можно потерять;
- начинать с малого;
- organic и paid разделять;
- UTM;
- не оптимизировать vanity metrics.

Hypothesis: 100–300 BYN для первого controlled test, пересмотреть по CPM/CPC.

Аудитория:

- followers автора;
- Минск;
- близкие интересы;
- retarget preview при допустимости.

## 6. Этап 2: первые 5–10 creators

Цель: repeatability.

Каналы:

- seller posts;
- case studies;
- creator referral;
- Reels;
- Telegram;
- communities;
- редакционные публикации;
- creative spaces.

Контент:

- процесс;
- ограниченность;
- результат аукциона;
- creator story;
- price logic;
- texture/scale;
- interior.

Главный asset — доказанный кейс, не banner.

## 7. Этап 3: аудитория bidplace

Предпосылки:

- creators;
- active lots;
- sales;
- categories;
- repeat visits.

Механики:

- editorial home;
- collections;
- new creators;
- upcoming;
- ending;
- sold stories;
- value content;
- cross-promotion.

Не обещать platform traffic, пока его нет.

## 8. Этап 4: локальные публичные люди

Offer:

- full concierge;
- private onboarding;
- provenance;
- protected contacts;
- branded page;
- media kit;
- auction support;
- privacy;
- representative.

Outreach:

1. знакомые creators;
2. локальные публичные люди;
3. managers;
4. PR;
5. concrete offer for concrete item.

Сообщение:

> У вас уже есть аудитория и значимая вещь. bidplace берёт на себя страницу, историю, торги и сопровождение.

## 9. Этап 5: крупные creators

Предпосылки:

- stable system;
- payments;
- anti-fraud;
- privacy;
- incidents;
- soft close;
- load tests;
- representatives;
- public cases.

Стратегия:

- не продавать абстрактную платформу;
- предложить конкретный launch;
- показать результаты;
- минимизировать нагрузку creator;
- white-glove support.

## 10. Контент

Канал роста, не образовательный продукт.

Темы:

- почему ручной труд стоит;
- человек за предметом;
- оригинал/копия;
- фактура;
- время;
- edition;
- provenance;
- интерьер;
- история владельца;
- путь до продажи;
- честный итог.

Форматы: short video, carousel, details, quote, interview, case.

Тон: простой, без снобизма, агрессии и anti-AI пафоса.

## 11. Формулировки вокруг ценности

- `bidplace — место, где ценят.`
- `У каждой значимой вещи есть история.`
- `Прямо от человека, который создал ценность.`
- `Не просто предмет.`
- `Ценность не должна уходить перекупщику.`
- `История, ограниченность, честная цена.`

Не использовать «элитный», «инвестиционное искусство», пафосные сравнения.

## 12. Метрики

Acquisition:

- reach;
- impressions;
- clicks;
- lot views;
- CPC;
- source.

Intent:

- CTA;
- registration;
- phone;
- bid attempts;
- bidders.

Auction:

- bidders;
- bids;
- first bid time;
- return visits;
- status views;
- final price;
- reserve.

Completion:

- winner response;
- payment;
- transfer;
- repeat intent;
- trust.

Позднее:

- second creator view;
- other lot participation;
- repeat purchase;
- direct platform traffic.

## 13. Интерпретация неуспеха

- мало views → announcement/ads;
- views без registration → trust/card/CTA;
- registration без bids → price/mechanic/item;
- one bid → слабая конкуренция;
- bids без payment → commitment/identity/handoff;
- sale без repeat seller → workload/price/value.

## 14. Launch pattern

```text
Fit review
→ item
→ provenance
→ card
→ preview
→ creator announcement
→ paid support
→ auction
→ handoff
→ interview
→ case
→ update product
```

## 15. Автоматизация после 5–10 sellers

- card templates;
- image checklist;
- asset generator;
- preview checklist;
- UTM;
- launch calendar;
- seller reminders;
- survey;
- case draft.

Не автоматизировать раннее:

- value selection;
- seller approval;
- provenance;
- incidents;
- pricing without human.
