# Исследовательский архив bidplace

## Назначение

`raw/` хранит исходные отчёты, фрагменты и выгрузки, на основе которых сформирована каноническая документация.

Эти файлы:

- могут содержать повторы;
- могут содержать неверные цифры;
- могут быть устаревшими;
- могут ссылаться на недоступные search IDs;
- могут смешивать факт и рекомендацию;
- не являются продуктовым решением.

## Правило чтения

Агент не должен читать `raw/` перед обычной coding-задачей.

Raw используется, если:

- проверяется происхождение тезиса;
- пересматривается рыночная гипотеза;
- требуется юридическая/конкурентная проверка;
- основатель просит исходный контекст.

## Приоритет источников

1. Решения основателя.
2. Реальные данные продукта.
3. Первичные интервью.
4. Официальные источники.
5. Академические/профессиональные исследования.
6. Внешние отчёты.
7. Отзывы и форумы.

## Маркировка

Вывод из raw не переводится в `Confirmed` без проверки или решения.
