# Список авторов

Адрес: `/authors`

## Цель

Простой список одобренных авторов. Тап → публичный профиль.

## Данные элемента

Портрет, имя (до 160, закладывать 2–3 строки), дисциплина (до 160).

Число работ API отдаёт — не обязано быть на элементе.

## Сортировка

По активности / по имени. Хватит.

Фильтра по дисциплине в API нет — не рисовать.

## Пагинация

Как у работ: сервер страницами, в UI сейчас обрезано. Заложить «ещё» или честный конец.

## Состояния

Пусто: «Пока нет авторов». Ошибка. Нет фото.

## На усмотрение дизайнера

Вид списка. Тот же компонент автора, что на главной.
