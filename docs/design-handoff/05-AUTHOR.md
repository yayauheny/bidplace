# Публичный автор

Адрес: `/seller/[slug]`  
Это витрина, не кабинет.

## Цель

Человек и его работы. Доверие. Переход к работе.

## Данные

| Поле | Публично | На странице |
|---|---|---|
| Имя | да | да |
| `@slug` | да | да |
| Портрет | да | да (обязателен при заявке) |
| Описание / практика | да | да |
| Дисциплина | да | сейчас в списке авторов есть, **на профиле нет** — показать |
| Страна | да | в API есть, на странице нет — показать человекочитаемо |
| Telegram, Instagram, сайт | если заполнены | да |
| Контакт передачи (телефон и т.п.) | **нет** | не показывать |
| Счётчики работ по статусам | да | можно у списка работ |

Галочка верификации — **будущее**. Место у имени заложить, в MVP не включать.

Follow и число подписчиков — не в этом цикле.

## Работы

Список его публичных работ (тот же элемент, что в каталоге). Фильтр по статусу продажи: идут / запланированы / завершены. «Загрузить ещё» — да (здесь в продукте уже есть).

Черновики и модерация **сюда не попадают**.

## Состояния

Нет работ. Сломанный портрет. Длинное имя и описание. Автор не найден.

Композиция. Не смешивать с кабинетом [11-ACCOUNT.md](./11-ACCOUNT.md).
