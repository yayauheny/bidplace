# Ставка

Подтверждение почты **сюда не вшивать** — сначала [08-CODE.md](./08-CODE.md) (окно по центру), потом этот экран.

## Порядок

1. «Поставить» на работе.
2. Гость → вход, возврат на работу, снова «поставить».
3. Почта не подтверждена → окно кода по центру. Email с регистрации, только код. Успех → сюда.
4. Правила не приняты → короткий шаг правил (один раз за аккаунт) → сюда. Вид: окно или экран, на усмотрение, не смешивать с суммой.
5. Экран или окно ставки: работа, сумма, подтверждение.
6. Повторная ставка в том же аукционе — сразу сумма, без кода и правил.

## Экран ставки — данные

- работа (название, миниатюра);
- текущая / минимальная сумма;
- поле суммы;
- три кнопки: **+1**, **+5**, **+100** (проверить вид на больших числах);
- подтверждение.

Пожелание: подтверждение **свайпом вправо**. Форма жеста — на усмотрение, главное явное подтверждение (ставка необратима).

Валюта BYN. Первая ставка может равняться стартовой. Подсказка шага не должна врать относительно минимума.

## После ответа сервера

Принято — видно новую цену / лидерство.  
Перебили в этот момент — «Ставка уже изменилась. Новая минимальная ставка — …»  
Своя работа / админ / торги не идут — не доходить до формы.

## Тексты ошибок (уже есть)

- «Введите сумму ставки в BYN.»
- «Минимальная ставка — {цена}.»
- «Ставка должна увеличиваться на {шаг}.»
- «Не удалось отправить ставку…»

## Замечание для реализации (не блокирует макет)

Сервер сейчас считает шаг таблицей 0,50 / 1 / 5 / 10 / 25, а не +1/+5/+100. Макет — с кнопками как заказано.
