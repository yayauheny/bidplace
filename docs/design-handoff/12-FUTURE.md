# Волна 2 — не эта встреча

Чтобы сетка не сломалась. Не рисовать как готовые экраны волны 1. Выключенные кнопки «скоро» не ставить.

Код волны 2 — после живого MVP и после оплаты самого сервиса.

| Что | Зачем помнить |
|---|---|
| Пресейл | работа ещё не готова, отдельная механика |
| Дроп, серия 10–100 штук | остаток количества, не одна строка «тираж» |
| Купить сразу на аукционе, пока не было ставок | как на eBay, в форме создания можно только место |
| Отзывы и рейтинг | после сделки, рядом со статусом в кабинете |
| Чат | не блокер продажи |
| Белорусский рубль, российский рубль, доллар | показ цены, не касса |
| Язык интерфейса | переключатель, шрифт уже читает латиницу |
| Именные коллекции автора | альбомы, не фильтр по категории |
| Коллекция купленного у покупателя | обычный профиль, по умолчанию не всем. Лайк себе — уже волна 1, не это |
| Вишлист «сделает ещё раз» | не делать; лайк — только сохранить работу |
| Перетаскивание порядка работ | приятно, не блокер |
| Карточки в рамке для сторис, если не вошло в волну 1 | то же окно «поделиться» |
| Подписка | когда сервис перестанет быть бесплатным |

Не закладывать: касса за вещь, курьер от площадки, скрытый резерв, услуги и мастер-классы как витрина, тёмная тема в этом цикле.
