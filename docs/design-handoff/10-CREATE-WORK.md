# Создать работу

Один проход. Модерация — **после всех шагов**, внутри. Отдельный экран «запланировать аукцион потом» не делать.

Если работу не допустили — кабинет: статус, **замечания**, редактирование той же карточки. Не гонять автора по кругу на полпути заполнения.

## Поля только один раз

Сейчас путают два разных смысла. В макете развести подписями:

| Смысл | Поле | Когда |
|---|---|---|
| Описание работы | история предмета | шаг «о работе», больше нигде не вводить |
| Тираж / единственность | короткая строка, не вторая «история» | там же, один раз |
| Как делали | этапы + фото | отдельный шаг, можно пустым |
| Продажа | старт сейчас или позже, конец, цена | шаг продажи, один раз |

Шаг «проверка» — **сводка без повторного ввода** тех же длинных текстов.

## Шаги (суть; местами можно менять)

1. О работе: название, описание, тираж, происхождение, категория, факты (техника, материал, размер, вес, год — необязательны), город, упаковка, текст передачи.
2. Медиа: фото обязательны (для макета лимит 8). **Видео опционально** — история/процесс, без видео работа полная.
3. Как создавалась — можно пропустить.
4. Продажа — **один контрол**:
   - начать **сейчас** или **в дату** (через неделю и т.п.);
   - дата/время конца;
   - стартовая цена BYN.
   В коде MVP можно оставить только «сейчас». Макет сразу с обоими, чтобы не платить второй раз.
5. Сводка → «Отправить на модерацию».

После апрува: если «сейчас» — торги по правилам окна; если дата — статус «запланированы» до старта. Дальше без ручного «ещё раз опубликовать».

## Необязательно для отправки

Техника, материалы, размеры, вес, год, упаковка, процесс, видео.  
Обязательно: название, описание, категория, тираж, происхождение, город, передача, ≥1 фото, цена и время аукциона.

Состояние вещи для авторской работы не спрашивать.

## После отправки

Пока «на проверке» — править нельзя. Статусы и замечания — в кабинете.

## Редактирование (тот же макет, не третий продукт)

Вход: кабинет → работа со статусом «нужны правки» или «отклонено» (или черновик).

Показать замечание модерации сверху. Поля те же, значения уже стоят. Можно поменять название, описание, размеры, фото, процесс, сроки продажи. Снова «Отправить на модерацию».

Не делать отдельный упрощённый «только название» без фото, если автор должен иметь возможность поправить всё.

## На усмотрение дизайнера

Число экранов-шагов, как выглядит «сейчас / позже» (сегмент, одна кнопка-переключатель — главное **не два разных продукта**). Как показать замечание модерации на форме правки.
