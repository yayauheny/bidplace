# Создать работу

Один проход. Модерация после всех шагов. Если не пропустили — в кабинете замечание и правка той же карточки.

Поля с одним смыслом не вводить дважды. Сводка в конце — без повторного набора тех же текстов.

Число экранов-шагов — на усмотрение, набор полей нет.

---

## О работе

| Поле | Обязательно |
|---|---|
| Название | да |
| Описание | да |
| Категория | да |
| Тираж или единственность (строка, не счётчик склада) | да |
| Откуда работа, что это его вещь | да |
| Город | да |
| Как передаёт | да |
| Техника, материалы, размер, вес, год, упаковка | нет |

Подсказка у названия, описания и категории: черновик, автор решает. Без неё отправить можно.

Состояние вещи «б/у» не спрашивать.

---

## Медиа

Фото обязательно, в макете до 8. Видео процесса можно не быть.

---

## Как создавалась

Можно пропустить. Этапы: название, текст, фото. Введение по желанию.

---

## Продажа — один шаг

Не два разных продукта «аукцион» и «магазин».

Выбор: аукцион или цена без торга.

**Аукцион:** начать сейчас или в дату; когда закончить; стартовая цена; сколько часов ждать победителя, если не выходит (в макете 24 / 48 / 72, по умолчанию 48). Если не вышел — продажа переходит к следующей ставке по сумме, администратор не нужен.

**Цена без торга:** цена; включить ли «предложить свою цену».

Кто пишет первым — если не подставилось из профиля.

Тираж «10 вещей» в волне 1 — строка в карточке. Пресейл и дроп как отдельный формат — [волна 2](./12-FUTURE.md).

**На встрече:** выключатель «купить сразу» на аукционе, пока не было ставок — место в этой форме сейчас или отложить.

После одобрения: «сейчас» — продажа по правилам окна; дата — статус «запланировано» до старта.

Перед отправкой на модерацию — красная плашка: [13-FOOTER-AND-COMPLAINT.md](./13-FOOTER-AND-COMPLAINT.md).

## После отправки — что можно менять

Две пачки полей. **Карточка** — что это за вещь. **Продажа** — как её сейчас продают. После одобрения карточку не открывать как эту форму: иначе автор подменит фото или цену у уже идущих торгов.

Карточка: название, описание, категория, тираж/единственность, происхождение, город, как передаёт, техника / материалы / размер / вес / год / упаковка, фото, история создания.

Продажа: аукцион или цена; даты и «сейчас / в дату»; стартовая или фикс-цена; окно связи 24 / 48 / 72; «предложить свою цену»; кто пишет первым (если не из профиля).

Контакт передачи (Telegram / телефон / Instagram) — в профиле автора, не в этой форме.

| Статус | Карточка | Продажа | Что ещё |
|---|---|---|---|
| Черновик | да, эта форма | да | не отправлять = просто не слать на проверку. Удалить черновик можно |
| На проверке | нет | нет | ждать. Ссылка «как на витрине» не нужна: работы ещё нет в каталоге |
| Нужны правки | да, замечание сверху | да | снова на модерацию. Пока не отправил — как черновик |
| Отклонено | да, замечание сверху | да | снова на модерацию. На витрине не видно |
| Запланировано | нет | нет | снять продажу — да, с причиной. Не «мало дают» |
| Идут торги | нет | нет | снять только форс-мажор / мошенничество / решение площадки. Не из‑за цены, не править старт |
| Стоит цена | нет | нет | снять **до** чужого «Купить». Цену в карточке не крутить: снял → потом выставить снова |
| Ждут ответ на предложение | нет | нет | «Купить» у других ещё живой. Снять фикс можно, пока никто не купил |
| Не продано | нет эту продажу | нет эту продажу | выставить снова: **только блок продажи** + причина. Карточка та же, без новой модерации |
| Продано, ждём связь / связались / передача завершена | нет | нет | снять нельзя. Контакт — в [кабинете](./14-CABINET-LOGIC.md), не поля работы |
| Сделка не состоялась | нет | нет эту продажу | выставить снова: блок продажи + причина из списка (не вышел / отказался / другое) |

На проверке, в анонсе и на живых торгах карточку кабинета не открывать формой создания. Публичная ссылка — да, когда работа уже на витрине.

Красная плашка перед **первой** отправкой на модерацию: не сниму только потому, что цена не понравилась. При «выставить снова» плашку не повторять.

### Никогда нельзя этой формой

- состояние «б/у»;
- артикул, складской счётчик, «номер заказа»;
- оплата картой на площадке, трек, курьер площадки;
- свои ставки, левые аккаунты, накрутка;
- после первой ставки на аукционе — выкуп (если место под него оставим, оно гаснет);
- после чужого «Купить» или принятого предложения — снять или сменить цену;
- подменить фото или текст, пока работа одобрена и висит.

Снять ≠ править. Снять — причина из списка, продажа кончается. Править — снова эта форма, только в черновике / правках / отклонено.

Выставить снова ≠ править старую продажу. Новые дата, цена, формат. Та же карточка вещи. Если нужно сменить фото или историю — это не самообслуживание волны 1: только если модерация вернула «нужны правки».

## На усмотрение

Как выглядит «сейчас / в дату». Как показать замечание модерации. Как выглядит экран «снять» и «выставить снова» (не та же длинная форма создания).
