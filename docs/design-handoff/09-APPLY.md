# Стать автором

Адрес: `/profile` (заявка)

## Цель

Заполнить публичный профиль и скрытый контакт передачи. Отправка → статус «на модерации». Продавать ещё нельзя.

## Шаги (смысл; порядок можно менять)

1. **Об авторе:** slug, имя, страна, дисциплина, описание, фото.
2. **Публичные ссылки:** хотя бы одна из Telegram / Instagram / сайт.
3. **Передача:** чем писать после сделки (Telegram / телефон / Instagram), значение контакта, кто пишет первым. Превью: что будет публично, что нет.

Финал: «Создать профиль».

Пока модерация — править нельзя. «Нужны правки» — снова можно.

## Поля и лимиты

См. таблицу в [00-BRIEF.md](./00-BRIEF.md). Контакты:

- Telegram: `@username` или `https://t.me/…`
- Instagram: `@username` или URL профиля
- Телефон: `+375…` (международный формат)

Тип «инфлюенсер» в форме не выбирать — всегда автор.

## Статусы

Нет заявки → на модерации → одобрен / нужны правки / отклонён / приостановлен.

Одобрен: Создать ведёт к новой работе. Кабинет — продажи/покупки, не эта форма.

## На усмотрение дизайнера

Как провести по шагам. Не показывать контакт передачи на публичной странице.
