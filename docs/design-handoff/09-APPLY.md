# Стать автором

Адрес: `/profile` (заявка)

Заполнить публичную страницу и скрытый контакт передачи. Отправка — статус «на модерации». Продавать ещё нельзя.

Порядок шагов можно менять, набор полей нет.

---

## Публично (после одобрения попадёт на [страницу автора](./05-AUTHOR.md))

| Поле | Обязательно |
|---|---|
| Короткий адрес страницы (латиница, цифры, дефис) | да |
| Имя | да |
| Страна | да |
| Дисциплина | да |
| Портрет | да |
| Текст о себе и практике | да |
| Цитата | нет |
| Факты: выставки, учёба, награды (заголовок, годы, ссылка) | нет |
| Telegram, Instagram или сайт — хотя бы одно | да |

Длины — в [00-BRIEF.md](./00-BRIEF.md).

Кнопка подсказки у текста о себе и цитаты: предлагает черновик, автор правит или стирает. Без подсказки отправить можно.

---

## Только победителю после продажи, не на витрине

| Поле | Обязательно |
|---|---|
| Чем писать: Telegram, телефон или Instagram | да |
| Значение контакта | да |
| Кто пишет первым | да |

Телефон: международный номер с кодом страны, пример `+375…` (не только Беларусь). Telegram и Instagram: `@имя` или ссылка.

На шаге показать превью: что будет публично, что нет.

---

## Статусы

Нет заявки → на модерации → одобрен / нужны правки / отклонён / приостановлен.

Пока на проверке — не редактировать. Вернули на правки — снова можно.

Одобрен: «Создать» ведёт к новой работе. Кабинет — не эта форма.

Тип «инфлюенсер» не выбирать — всегда автор.

Короткие ссылки на правила для авторов и на запрещённые товары — [13-FOOTER-AND-COMPLAINT.md](./13-FOOTER-AND-COMPLAINT.md). Простыню в форму не класть.
