# Вход и регистрация

Адреса: `/login`, `/register`

Аккаунт по почте и паролю. Google и Telegram как вход не рисовать.

## Регистрация — поля

| Поле | Обязательно | Лимит |
|---|---|---|
| Имя | да | 120 |
| Почта | да | 255 |
| Пароль | да | от 8 |

Имя аккаунта не становится публичным именем автора. Телефон не спрашивать.

## Три галочки, без них аккаунта нет

Каждая строка — короткая фраза. Синяя ссылка открывает документ на отдельной странице. Простыню в форму не класть.

- согласен с пользовательским соглашением;
- согласен с политикой персональных данных;
- даю согласие на обработку персональных данных.

Отдельно: «мне есть 18 лет». Паспорт не просим.

Список документов и короткие фразы — [13-FOOTER-AND-COMPLAINT.md](./13-FOOTER-AND-COMPLAINT.md). Полные черновики — [../legal/drafts/](../legal/drafts/).

## Вход

Почта и пароль. Ошибки по-русски. После входа — туда, откуда пришли (ставка, создать, кабинет).

Код с почты на регистрации не нужен. Он нужен перед первой ставкой, покупкой или предложением цены, [08-CODE.md](./08-CODE.md).

## Сброс пароля

Экраны есть в волне 1: «забыли пароль» — почта; письмо; новый пароль по ссылке. Ошибки: ссылка недействительна, пароль короткий. После сброса — вход.

В макете ошибки входа: пустая или кривая почта, короткий пароль, неверная пара.

## На усмотрение

Один экран с переключением или два. Вид полей.
