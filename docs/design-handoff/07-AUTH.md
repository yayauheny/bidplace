# Вход и регистрация

Адреса: `/login`, `/register`

## Цель

Аккаунт по **email + пароль**. Google, Telegram и другие провайдеры в этом цикле **не рисовать** (только если отдельно оценено сверх базы).

## Регистрация — поля

| Поле | Обязательно | Лимит |
|---|---|---|
| Имя | да | 120 |
| Email | да | 255 |
| Пароль | да | от 8 |
| Телефон | нет | 32 |

Имя аккаунта **не** становится публичным именем автора.

## Вход

Email + пароль. Ошибки по-русски.

После входа: возврат туда, откуда пришли (ставка, создать, кабинет).

## Не в этом экране

Код с почты — [окно по центру](./08-CODE.md) перед первой ставкой. При регистрации код не нужен, чтобы смотреть сайт. Email при регистрации **обязателен** — окно ставки email заново не собирает.

Ошибки полей обязательны в макете: пустой/некорректный email, короткий пароль, неверная пара вход.

## На усмотрение дизайнера

Один экран с переключением вход/регистрация или два. Вид полей.
