# Главная

Адрес: `/`

## Цель

Понять, что это площадка авторских работ. Увидеть сильные работы и авторов. Найти работу текстом. Перейти в списки. Путь стать автором / создать.

## Данные (есть сейчас)

Три списка с сервера, **без** отдельного поля «featured»:

| Список | Сколько | Сортировка |
|---|---|---|
| Аукционы / сильные работы | до 3 | по активности |
| Авторы | до 4 | по активности |
| Новые работы | до 3 | по дате публикации |

Элемент работы: обложка, название, автор (`@slug` + фото), цена BYN, статус, дата конца.  
Элемент автора: портрет, имя, дисциплина. Число работ в API есть — в списке сейчас не показываем.

Одна работа может попасть и в «аукционы», и в «новые». Так можно.

## Поиск

Только **поле на главной**. Ввод текста. Отдельного экрана поиска нет.

По подтверждению запроса — открыть **список работ**, отфильтрованный этим словом (см. [02-WORKS.md](./02-WORKS.md)). Пустой запрос не искать. Нет результатов — честный пустой список.

Ищутся: название, описание работы, материалы, имя автора.

## Шапка

Поиск, меню (открытие меню), вход / аккаунт, «Создать», язык — состав обязателен, раскладка на усмотрение.

«Создать»: гость/покупатель → стать автором; одобренный автор → новая работа.

С главной: «все работы», «все авторы», открыть работу, открыть автора.

## Заложить на главной (сверх простого списка)

1. **Голосование** — выбрать лучшего автора (простая кнопка «проголосовать»). Не отдельная соцсеть. API нет.
2. **Автор недели** — на этой же главной после выбора победителя: фон, автор, 1–3 его работы, переход в профиль и на работу. Данных «недели» в API нет: для макета взять одного автора из списка.

Оба блока сверх исходного ТЗ — подтвердить объём. Если не влезает: компактные кадры, не отдельный сервис.

Не делать бесконечную ленту и рекомендации «как маркетплейс».
