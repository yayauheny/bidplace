# Design data packet

Что нужно в Figma, чтобы макеты не врали. Не выдумывать поля, которых нет в продукте.

Демо-сид локальной базы — удобный старт, но **не покрывает** крайние длины и «бедные» состояния. Ниже: что уже можно взять, чего не хватает.

Пометка **NEEDED_FOR_DESIGN_FIXTURE** — в рабочих данных этого нет или недостаточно.

## Works

Нужно **8–12** работ.

Покрыть:

| Случай | В сиде / модели |
|---|---|
| Керамика / объект | да |
| Текстиль | да |
| Графика / эстамп | да |
| Живопись как категория | **NEEDED_FOR_DESIGN_FIXTURE** — в справочнике сейчас одна категория «Авторская керамика» |
| Портретное фото | часть кадров |
| Горизонтальное фото | часть кадров |
| Одно фото | типичный сид: 1 обложка |
| Много фото (4–8) | **NEEDED_FOR_DESIGN_FIXTURE** для галереи; процессные фото есть отдельно |
| Короткое название | да |
| Очень длинное название (2–3 строки) | **NEEDED_FOR_DESIGN_FIXTURE** |
| Длинная история (3–6 абзацев) | **NEEDED_FOR_DESIGN_FIXTURE** (в сиде 1–2 предложения) |
| Без процесса | возможно; нужен явный пример | **NEEDED_FOR_DESIGN_FIXTURE** |
| С 4–6 шагами процесса + фото | в сиде у части работ 4 шага |
| Аукцион идёт / запланирован / завершён | да |
| Ноль ставок | да |
| Несколько ставок | мало; **NEEDED_FOR_DESIGN_FIXTURE** для истории из 5–8 строк |
| Уникальность: единственный / тираж / малая серия | да |
| Без опциональных фактов (нет техники/размера/года) | **NEEDED_FOR_DESIGN_FIXTURE** |
| Сломанное фото | **NEEDED_FOR_DESIGN_FIXTURE** |

В текущем discovery-представлении цена и дата видны. Если новый макет их прячет — это exploration, не текущие данные.

Видео **не готовить** как MVP-контент.

## One complete flagship example

Соберите **одного автора + одну работу**, которые проходят:

Главная → страница работы → профиль автора

без подмены полей. Ниже — только подтверждённые данные.

### Автор

- портрет (реальное фото человека, не сток «с аукциона»);
- полное имя;
- slug;
- дисциплина;
- страна;
- короткое описание практики (лучше 4–8 строк, даже если сид короче — **NEEDED_FOR_DESIGN_FIXTURE** для длины);
- Telegram и/или Instagram и/или сайт.

Не класть в публичный макет телефон передачи.

### Работа

- название;
- обложка;
- ещё 4–7 кадров: общий вид, макро/фактура, в интерьере или в руке, деталь, оборот если уместно — **NEEDED_FOR_DESIGN_FIXTURE**, если берёте сид с одним кадром;
- история предмета (полноценная глава, не одна строка) — **NEEDED_FOR_DESIGN_FIXTURE** для длины;
- уникальность / ценность (коротко, 1–2 предложения);
- происхождение;
- введение процесса + 4–6 шагов (название, текст, фото) — в сиде заготовка есть;
- факты: техника, материал, размеры, год, город, передача, упаковка;
- аукцион: статус «идут», стартовая и текущая цена в BYN, конец, 3–6 ставок с псевдонимами `Bidder ……` — история ставок **NEEDED_FOR_DESIGN_FIXTURE**;
- 2–3 другие работы того же автора (related works).

Ближайший сид-якорь: автор **Анна Морозова**, живая работа вроде «Стакан для кистей „Голубая комета“» — но для флагмана всё равно доберите длину текстов и галерею.

Исследовательский флагман «Тихий берег / Полина Мирош / 6 кадров» можно брать **только** как visual exploration, с маппингом на реальные поля выше, без выдуманных follow/wishlist.

## Auction values to keep honest

- валюта **BYN**;
- копейки возможны (0,50);
- первая ставка = стартовая;
- дальше — таблица шагов;
- псевдонимы не похожи на email и не на настоящее имя;
- не рисовать «12 watching» и фейковый дефицит.

## Copy you may typeset (exists in product UI)

Можно использовать как тон, не как священный манифест:

- «Работы в bidplace»
- «Пока здесь тихо»
- «Торги идут» / «Скоро» / «Завершено»
- «Автор не добавил историю создания.»
- «Ставок ещё нет.»
- «Сделать ставку» / «Поставить» / «Войти»

Манифест «Работы с историей — напрямую от авторов» — из exploration, не из API.

---

## Do not put in MVP mockups

- избранное / сохранить работу;
- «следить»;
- видео процесса (optional post-MVP fixture отдельно, не как обязательный слой);
- корзина, чекаут, карта;
- NFT / wallet;
- фильтр «тип работы», пока нет поля;
- вторая валюта;
- чат, колокольчик уведомлений, счётчики подписчиков.
