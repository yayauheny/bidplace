# Creator profile

Адрес: `/seller/[slug]`  
Это публичная страница автора, не кабинет.

Дизайнер выбирает композицию. Ниже — данные, действия и состояния.

---

## Purpose

Показать человека и его работы. Покупатель решает, доверяет ли он автору, и переходит к работе.

Не показывать: рейтинг, продажи, подписчиков, verified, награды — таких данных нет.

---

## Information groups

### Identity

| Смысл | Обязательно | Публично? | На профиле сейчас |
|---|---|---|---|
| Полное имя или название | да | да | да |
| Адрес страницы (`slug`) | да | да | `@{slug}` |
| Портрет | да при заявке | да | да |
| Дисциплина | в форме да, на сервере может подставиться «Автор» | да | **в каталоге авторов да, на странице профиля нет** |
| Страна | да | да | **в API есть, на странице нет** |
| Короткое описание / практика | да | да | да |
| Telegram / Instagram / сайт | нет, по отдельности | да, если заполнены | да, только эти три |
| «Основная публичная ссылка» | да хотя бы одна ссылка при заявке | поле есть | **на профиле не показывается отдельно** |
| Контакт для передачи (телефон / TG / IG) | да | **нет**, только после сделки | не показывать |
| Тип продавца (автор / инфлюенсер) | да в данных | да | не показывается; в форме всегда «автор» |
| Счётчики работ по статусам | считаются сервером | да | да, у фильтра работ |

Имя до ~160 знаков, дисциплина до 160, описание — длинный текст. Страна в демо часто `BY`, не «Беларусь».

### Description / practice

Единственное текстовое поле профиля: **короткое описание**.

Нет отдельных полей «биография», «практика», «манифест», «образование». Если нужна глава «практика» — это это же описание, не новое поле.

### Links

Публичные, если заполнены:

- Telegram
- Instagram
- сайт (URL)

Приватные (не сюда): способ передачи и значение контакта, кто пишет первым.

Устаревшее поле «одна социальная ссылка» в API ещё есть, в профиле как сайт больше не используется.

### Works and sale states

Список опубликованных работ автора. Те же данные работы, что в каталоге (включая цену и статус в текущем представлении).

Фильтр по статусу продажи:

| Статус | Счётчик |
|---|---|
| Идут торги | с сервера |
| Запланированы | с сервера |
| Завершены | с сервера |

Сортировка: по активности, сначала новые, сначала дешевле, сначала дороже.

Пагинация: 20, есть «Загрузить ещё».

В каталог автора попадают только уже опубликованные аукционы. Одобренная работа без расписания **не видна**.

Отдельного слота «текущий релиз» нет. Ближайший аналог — работы со статусом «идут торги» или первая при сортировке по активности.

## States

| Состояние | Поведение |
|---|---|
| Нет фото в файле | у одобренного автора фото обязано быть; если файл не загрузился — плейсхолдер + «Повторить» |
| Нет работ | «У автора пока нет опубликованных работ» |
| Длинное имя | в каталоге авторов сейчас одна строка; на профиле заголовок может переноситься |
| Длинное описание | обычный текст, без «ещё» |
| Загрузка | «Загружаем работы автора…» |
| Автор не найден | «Автор не найден» |
| Ошибка работ | «Не удалось загрузить работы автора» |
| Нет публичных ссылок | ссылки просто отсутствуют |

## Must not appear on MVP

- «Следить за автором»
- счётчик подписчиков
- «похожие авторы» как алгоритм
- чат с автором
- публичный телефон из заявки

---

## Gaps

- Дисциплина есть, но на странице профиля не показана — в каталоге авторов показана.
- Нет состояния «без портрета» в данных: фото обязательно. Для макета всё равно нужен сломанный кадр.
- Кабинет автора ≠ эта страница. Кабинет сейчас — форма заявки/профиля, не витрина своих работ.
