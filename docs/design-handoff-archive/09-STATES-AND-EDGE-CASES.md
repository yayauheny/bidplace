# States and edge cases

Чеклист для дизайн-QA. Не 118 отдельных бордов: покрыть эти строки.

«Supported today?» — есть ли это в текущем интерфейсе, не «нарисовано ли в Pen».

Будущие состояния (follow, save, video, фикс. цена, presale, платежи, чат, уведомления) — [13-FUTURE-PRODUCT.md](./13-FUTURE-PRODUCT.md). Не включать их в MVP-набор, если там `STATE MODEL NOT YET DEFINED` или `NO — future only`.

---

## Global

| State | Where | Trigger | Expected product behavior | Supported today? |
|---|---|---|---|---|
| Loading | любой публичный список/страница | первый запрос | «Загружаем…» или эквивалент, без фейковых работ | да |
| Network error | то же | 5xx / сеть | честный текст + Повторить | да |
| Empty | списки | нет данных | честный empty, не заглушки-лоты | да, тексты общие |
| Long Russian text | имя, название, описание | длинные строки | перенос, без обрезки смысла в критичных местах | частично: discovery режет имя/название |
| Missing / failed media | фото работы и автора | битый URL | тот же кадр, плейсхолдер, Повторить | да |
| Reduced motion | движение в UI | системная настройка | без лишней анимации, ставка доступна | да в коде |
| Zoom / large text | кнопки, формы | системный масштаб | цели ≥ 44px, текст читаем | заложено, приёмка открыта |

## Home

| State | Where | Trigger | Expected | Today? |
|---|---|---|---|---|
| Full empty | Главная | нет публичных работ и авторов | «Пока здесь тихо» | да |
| No auctions, authors exist | секция аукционов | нет top list | скрыть секцию, не выдумывать работы | да (секция просто пропадает) |
| No authors | секция авторов | пустой список | скрыть секцию | да |
| Load error | страница | API home упал | ошибка + повтор | да |
| Featured missing | Главная | нет выбранной работы | не выдумывать featured-сущность | featured нет вообще |

## Works

| State | Where | Trigger | Expected | Today? |
|---|---|---|---|---|
| Loading list | `/works` | запрос | загрузка без фейковых работ | да |
| Empty catalog | `/works` | нет работ | «Пока нет работ» | да |
| Empty after filters | `/works` | слишком узкий фильтр | лучше отдельный текст | нет, тот же empty |
| One category only | фильтр | реальные данные | одно значение или «Все» | да |
| Messy material strings | фильтр Материал | свободный текст | длинные пункты | да, сырые строки |
| End of list | `/works` | > 20 работ | продолжение списка или честный конец | **нет load more** |
| Failed work image | discovery-работа | фото не загрузилось | плейсхолдер | да |

## Work Detail

| State | Where | Trigger | Expected | Today? |
|---|---|---|---|---|
| LIVE | аукцион | идут торги | цена, таймер, ставка | да |
| SCHEDULED | аукцион | до старта | начало, без ставки | да |
| ENDED | аукцион | после конца | «Торги завершены» | да |
| ENDED, no bids | история | никто не ставил | «Ставок ещё нет.» + завершено | да |
| ENDED, with winner | история / заказ | была ставка | лидер в истории; победителю — заказ | да |
| Loading page | страница | запрос | «Загружаем предмет…» | да |
| Load error | страница | 404/сеть | «Не удалось загрузить предмет» | да |
| Media error | галерея | кадр не грузится | плейсхолдер + повтор | да |
| One image | галерея | только обложка | без фейковых кадров сзади | да |
| Many images | галерея | 2–8 фото | понятная навигация по кадрам | частично |
| No creation story | процесс создания | автор пропустил | «Автор не добавил историю создания.» | да |
| Step without photo | процесс | текст без кадра | только текст | да |
| Guest | CTA | не вошёл | «Войти» | да |
| Email gate | CTA | почта не подтверждена | «Подтвердите email» | да |
| Rules gate | CTA | правила не приняты | «Правила участия» | да |
| Admin | CTA | роль админ | без формы, пояснение | да |
| Self / author of work | CTA | своя работа | не давать ставить | сервер да, UI нет |
| Stale bid | диалог | цену перебили | новый минимум, повтор | да |
| Share success / fail | кнопка | копирование | «Ссылка скопирована» / ошибка | да |
| Long title | идентичность работы | 2–3 строки кириллицы | название остаётся читаемым | нужно проверить в макете |
| Empty condition | факты | поле пустое | не показывать «Состояние: пусто» | сейчас строка может остаться |

## Creator

| State | Where | Trigger | Expected | Today? |
|---|---|---|---|---|
| No works | профиль | нет публикаций | честный empty | да |
| Failed portrait | идентичность автора | фото не грузится | плейсхолдер, не сток | да |
| No portrait in data | заявка | — | в продукте фото обязательно; в макете всё равно нужен missing | только ошибка загрузки |
| Long name | автор | 30–60 букв | перенос | в каталоге авторов — 1 строка |
| Long bio | описание | несколько абзацев | читаемый текст | да, без collapse |
| No socials | иконки | поля пустые | не показывать мёртвые иконки | да |
| 404 | `/seller/…` | нет автора | «Автор не найден» | да |

## Auction / Bid

| State | Where | Trigger | Expected | Today? |
|---|---|---|---|---|
| First bid = start price | форма | ещё никто не ставил | минимум = стартовая | да |
| Increment hint | форма | сумма не по шагу | текст про шаг | да |
| Soft close | таймер | ставка в последние 60 с | конец отодвигается; сервер | логика да, отдельный UI нет |
| Leading / outbid | покупки | свои ставки | статусы «Побеждаете» / «перебита» | да |
| Order after win | покупки / работа | победа | ссылка на заказ | да |
| Handoff privacy | заказ | кто пишет первым | покупатель видит контакт автора **или** автор видит email | да |

## Forms

| State | Where | Trigger | Expected | Today? |
|---|---|---|---|---|
| Field error | заявка / работа / ставка | невалидно | ошибка у поля | да |
| Disabled while pending | модерация | статус «на проверке» | нельзя тихо править | да |
| Photo required | заявка | нет файла | блок отправки | да |
| Image limit | работа | 8–10 файлов | честный лимит | форма 10, сервер 8 |
| Skip creation story | шаг 3 | пусто | можно к проверке | да |
| Review before submit | шаг 4 / шаг 3 профиля | перед модерацией | сводка, без приватных полей на превью профиля | да |
| Login validation | вход | пустой email/пароль | русские сообщения | да |

Закладывайте эти строки в макеты как обязательный набор, а не отдельный «state dump» на каждую комбинацию.
