# Works and filters

Адреса:

- Работы: `/works`
- Поиск: `/search?q=…`
- Авторы: `/authors` (соседний каталог, не фильтр работ)

Дизайнер выбирает, как показать список и фильтры. Ниже — данные, правила и состояния.

---

## Purpose

Дать обозреть публичные работы с аукционом, сузить набор и открыть работу.

Публично видны только одобренные работы одобренных авторов, у которых есть аукцион в статусе **запланирован / идёт / завершён**. Черновики и работы на модерации сюда не попадают.

Это каталог продаж, не персонализированная лента.

---

## Search

Отдельный маршрут `/search`, не встроенный в `/works`.

Плейсхолдер сейчас: «Найти предмет или автора». На `/authors`: «Найти работу или автора».

### Что ищется

| Где | Поля |
|---|---|
| Работы | название, история (story), материалы, имя автора |
| Авторы | имя, адрес профиля (`slug`), короткое описание |

Не ищется: техника, город, происхождение, публичный id, дисциплина автора.

Пустой запрос: «Введите запрос».  
Нет результатов: «Ничего не найдено».

Поиск показывает до 8 авторов и до 12 работ, без «загрузить ещё».

## Filters

Фильтры есть **на `/works`**. На Главной и в Поиске их нет.

Значения категорий, авторов, материалов и уникальности приходят с сервера (facets). Это не зашитый в макет справочник.

| Filter | Values / source | Current code | Product intent | Notes |
|---|---|---|---|---|
| Категория | Список с сервера: id + название + счётчик | Есть | Категория обязательна у работы | В демо-данных сейчас **одна** категория: «Авторская керамика». Таксономия продукта не утверждена списком. |
| Автор | Одобренные авторы, у которых есть видимые работы | Есть | Да | Фильтр по точному `slug`, в меню — имя |
| Материал | Разные **полные строки**, как их вписали авторы | Есть | Материалы — свободный текст | Это не справочник «керамика / лён». Пункт может быть «Шамотная глина, глазурь» |
| Цена | Три готовых диапазона в интерфейсе | Есть | Цена есть у аукциона | «До 500 BYN», «500–1 500 BYN», «От 1 500 BYN». Произвольный ввод min/max в UI нет, в API — есть |
| Статус | Идут / Запланированы / Завершены | Есть | Да | Сейчас дублируется: выпадающее «Статус» и отдельные контролы с счётчиками. Сброс — пункт «Все» |
| Уникальность | Точное совпадение со строкой автора | Есть | Поле уникальности/тиража обязательно | В демо: «Единственный экземпляр», «Ограниченный тираж», «Малая серия». Это не enum |
| Год | Диапазон yearFrom–yearTo | **API есть, UI нет** | Год у работы желателен | `CODE_ONLY` в API |
| Тип работы | — | **NOT FOUND** | В Pen v2 контрол спрятан | Нет поля в модели. Не обещать, пока нет решения |
| Wishlist / сохранённые | — | **NOT FOUND** | Не MVP | DESIGNED_POST_MVP — [13](./13-FUTURE-PRODUCT.md) |

У каждого фильтра есть значение **«Все»**.

## Sorting

На `/works`:

| Код | Подпись в UI |
|---|---|
| `newest` | Сначала новые |
| `activity` | По активности |
| `endingSoon` | Скоро завершатся |
| `priceAsc` | Сначала дешевле |
| `priceDesc` | Сначала дороже |

Экран Работ по умолчанию открывается с **«По активности»**.

«По активности» для работ: сначала идущие торги, потом запланированные, потом завершённые; внутри — больше ставок, выше цена, ближе дедлайн.

«Скоро завершатся»: тоже сначала живые/запланированные, затем завершённые.

«Сначала новые»: по дате первой публикации работы.

На `/authors` сортировка другая: «По активности» / «По имени».

## Discovery work — available data

Что продукт знает о работе в каталоге. Как это показать — решение дизайнера.

| Данные | Есть в представлении сейчас? |
|---|---|
| Фото (первое / обложка) | да |
| Название | да |
| Автор (фото + `@slug`, не полное имя) | да |
| Цена | да |
| Статус торгов | да |
| Дата окончания | да |
| Уникальность / короткий дескриптор | данные есть, в discovery **не используются** |
| Число ставок | данные есть, **не используются** |
| Дисциплина автора | нет |

Если листинга нет (в публичном каталоге не бывает): цена «Цена появится позже», статус «Скоро».

### Цена и дедлайн — продуктовый конфликт

| | Current implementation | Approved product (MVP RFC) | Design exploration |
|---|---|---|---|
| Цена | Показана | Посетитель «видит цену и время» | Скрыть в discovery |
| Дедлайн / статус | Показаны | Показаны | Скрыть |
| Число ставок | Не показывается | Не требуется в discovery | Скрыть |

Не смешивать слои без решения основателя. Вопрос: [12-OPEN-QUESTIONS.md](./12-OPEN-QUESTIONS.md).

## Pagination / load more

| Экран | Поведение |
|---|---|
| `/works` | Сервер умеет страницы по 20. **Интерфейс показывает только первую страницу.** Продолжения списка нет |
| Профиль автора | Есть «Загрузить ещё» |
| `/authors` | Первая страница, без продолжения |
| Поиск | 8 + 12, без продолжения |

Для каталога закладывайте конец списка: бэкенд пагинацию уже умеет, экран Работ — нет.

## Empty / loading / error

| Состояние | Текст сейчас |
|---|---|
| Загрузка | «Загружаем работы…» (может быть скрыт за плейсхолдерами) |
| Обновление фильтров | «Обновляем работы…» |
| Ошибка | «Не удалось загрузить работы» + Повторить |
| Пусто (нет работ вообще или фильтр ничего не дал) | «Пока нет работ» / «Здесь появятся авторские предметы для торгов.» |

Отдельного текста «по фильтрам ничего не найдено» нет — тот же empty.

Сломанное фото: плейсхолдер той же роли + «Повторить», без подмены чужой картинкой.

## Authors directory

`/authors` — каталог авторов, не фильтр работ. Те же данные автора, что на Главной. Пусто: «Пока нет авторов» / «Авторы не найдены».

---

## Gaps

- Категорий в реальных данных почти нет — фильтр выглядит пустым или с одним пунктом.
- Материалы и уникальность — сырой авторский текст, меню может быть длинным.
- Нет фильтра по году в UI.
- Нет пагинации на `/works`.
- Не решено, входят ли цена и дедлайн в discovery-представление.
