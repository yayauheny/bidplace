# Auth, account, roles

Коротко: кто что может в интерфейсе.

---

## Guest

Может:

- открыть Главную, Работы, Авторов, Поиск, работу, профиль автора;
- пользоваться поиском и фильтрами;
- нажать «Поделиться»;
- перейти к входу / регистрации.

Не может: ставить, видеть свои ставки, подавать заявку автора (сначала аккаунт).

На живых торгах CTA: **«Войти»**, возврат на ту же работу.

---

## Authenticated buyer

Регистрация: **имя, email, пароль** (от 8 символов). Телефон в форме есть, не обязателен. Других способов входа нет (не Google, не Telegram).

После входа:

- всё, что гость;
- раздел **Покупки** (`/me/activity`);
- ставка — только после подтверждения email и принятия правил;
- заявка стать автором.

Имя в аккаунте (display name) **не становится** публичным именем автора само. Публичное имя задаётся в заявке отдельно.

---

## Creator

Это тот же пользователь плюс заявка.

| Пока не одобрен | После одобрения |
|---|---|
| Видит статус заявки | «Создать» ведёт к новой работе |
| Работы создавать нельзя | Может создавать работы и планировать аукцион |
| В меню: «Заявка продавца» | В меню: «Кабинет» |

Кабинет = `/profile` (форма профиля), не отдельный список своих работ.

Ставить на **свою** работу нельзя. На чужие — можно, как покупатель.

---

## Admin / moderator

Отдельная роль. В меню: **Модерация**, без Покупок.

Может одобрять / возвращать / отклонять авторов и работы, сопровождать срыв передачи.

Не может ставить ставки. На странице работы это сказано прямо.

---

## Auth methods

Только email + пароль. Сессия в браузере.

Подтверждение почты: код из письма, **обязателен перед первой ставкой**, не обязателен чтобы смотреть сайт.

Правила сервиса: отдельный текст с версией, принятие один раз перед первой ставкой.

## Account actions

| Пункт | Кто видит |
|---|---|
| Войти | гость |
| Стать продавцом | вошёл, заявки нет |
| Заявка продавца | заявка есть, ещё не одобрен |
| Кабинет | одобренный автор |
| Покупки | вошёл, не админ |
| Модерация | админ |
| Выйти | вошёл |

---

## Global «Создать»

Продуктовое намерение: постоянная роль-зависимая точка входа.

| Кто | Куда должно вести | Как сейчас |
|---|---|---|
| Гость | вход, затем заявка | мобильный «+» → вход; десктоп «Создать» **скрыта** |
| Покупатель без заявки | заявка | мобильный «+» → `/profile`; десктоп скрыта |
| На модерации / правки | честный статус | мобильный «+» → профиль; десктоп скрыта |
| Одобренный автор | новая работа | и десктоп, и мобила → `/products/new`. Подпись «Создать», доступность «Добавить работу» |
| Админ | не создавать работу | кнопки нет |

Исследование просит подпись вроде «Стать автором» для гостя. Сейчас везде «Создать» / «Стать продавцом».

## What navigation changes

Гость: Войти.  
Вошёл: иконка аккаунта вместо Войти.  
Админ: Модерация вместо Покупок, без Создать.  
Одобренный автор: появляется десктопное Создать.

Исследования иногда рисуют отдельную нижнюю навигацию (Главная / Обзор / Создать / Профиль). В текущем продукте те же назначения живут в шапке и меню — это связь маршрутов, не требование к chrome.

Сохранённые работы и «мои авторы» в аккаунте — DESIGNED_POST_MVP, списков ещё нет. Не добавлять в меню MVP. См. [13-FUTURE-PRODUCT.md](./13-FUTURE-PRODUCT.md).
