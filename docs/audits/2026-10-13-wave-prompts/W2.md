# WAVE W2 — One fluid container contract in `AppShell`

Model: sol, effort medium. Base: the accepted result of W1 (branch `ds/w2-container`). This wave touches every screen's width; read the whole wave before editing.

## Why

Today the layout assumes a phone: `AppShell` defaults `contentMaxWidth` to `layout.phoneWidth` (390), so on a wide window every screen is a 390 column (440 appears in several places too); `public-seller-screen` alone passes 1280. There are six names for 390 (`layout.phoneWidth/contentMaxWidth/headerMaxWidth/discoveryMaxWidth/productDetailMaxWidth/productHeroContentWidth`, `size.phoneWidth`), a separate `creatorContentMaxWidth`, a `size.dockReserve` read by ~8 places, and unused `breakpoint.*` tokens (all 99999).

Confirmed designer decision (founder, 2026-10-13): **desktop** content container max width **1280**, centered, with no mandatory side padding; **mobile** 100% width with a **12 px** horizontal gutter; **tablet** 100%; vertical spacing comes from each Figma composition (always even numbers); Safe Area is separate and applied once; responsiveness comes from containers/flexbox, breakpoints only when the composition itself changes. Figma (live file `pAPQo6cADmG5XzVmBX76EE`) confirms the 12 px gutter (content x = 12, width 366 in 390 frames). Figma has **no** desktop/tablet frames yet: do not invent desktop compositions; 1024/1440 stay `NEEDS-FIGMA` beyond this width contract.

## The contract (implement exactly this)

```
outer:   width: '100%', maxWidth: layout.contentMax + 2 * layout.gutter, paddingHorizontal: layout.gutter, alignSelf: 'center'
content: min(100% - 2*gutter, contentMax)      // layout.contentMax = 1280, layout.gutter = 12
```

Safe Area horizontal/top/bottom is applied once, by `AppShell`, nowhere else. Full-bleed atmosphere/blur layers are siblings outside the column, never fixed with `overflow`.

## Boundaries

- Screens are not re-laid-out. If a screen breaks at 1024 or 1440 because of the new width, fix it minimally **inside that same screen change** (no "escape" prop on `AppShell`, no per-screen max width).
- `SafeAreaProvider` is not changed. No new dependency. Decorative/atmosphere layers keep their implementation.
- Do not add breakpoints. A breakpoint is allowed only for a change of composition and must be a local named constant.
