# WAVE W5 — One Tabs, one card grid, one check mark (no new dependencies)

Model: terra, effort high. Base: the accepted result of W4 (branch `ds/w5-primitives`). The widths from W2 (`layout.contentMax`, `layout.gutter`) are already in place.

## Why

The same job is solved several times: tabs exist as `FigmaTabs.tsx` plus a web fork `FigmaTabs.web.tsx` that differ in counter rendering and behavior; card grids are written four different ways (`WorkCoverCardGrid`, a padded-rows grid and a `flexWrap` grid in two screens, fixed breakpoints 700/1000); `FilterOptionRow` draws a checkmark with a rotated bordered box and switches look by the _name of the screen_ (`variant` like `directions`); `WorkGallery` calls `setState` on every scroll event.

Figma facts (live file `pAPQo6cADmG5XzVmBX76EE`):

- **Tabs have two patterns.** (a) Catalog tabs (section 05, node `7008:1756`): labels sized by content, left-aligned at x = 12 / 117 / 211 / 287, height 25, 2 px underline under the active one. (b) Author profile tabs (section 07, frame `7008:12975`, row `7008:13047`): equal columns of 122 px starting at x = 12, text centered, vertical padding 16, optional small count chip next to the label. One component must support both with one prop (for example `fill`); do not collapse them into one.
- **Author work cards** are a single column of 366x488 cards with a 20 px gap at 390. Desktop/tablet frames do not exist (`NEEDS-FIGMA`): keep today's maximum number of columns per screen as the `max`.

## Do

1. **Tabs.** Keep one React Native implementation in `FigmaTabs.tsx`; delete `FigmaTabs.web.tsx` after checking what its web-only behavior was (record it in the report). Required: `role="tablist"` / `role="tab"`, `aria-selected`, a roving focus, ArrowLeft/ArrowRight/Home/End on web, visible focus ring, one way of drawing the count chip, a `fill` (equal columns) mode and the default content-width mode. `rg -n "FigmaTabs" apps/mobile/src` first and list every consumer; each keeps its current look unless it was relying on the removed divergence. Do not change tab typography tokens in this wave; in the report state which typography token the tab label uses.
2. **Grid.** Extend the **existing** `WorkCoverCardGrid` (do not create a second grid component) so columns come from the _measured container width_: `columns = clamp(floor((width + gap) / (minCard + gap)), 1, max)`, with `minCard`, `gap` and `max` as props whose defaults come from tokens or from the current screen values. Delete the 700 / 1000 breakpoints. Move the screens that render work cover cards onto it (the public author profile in `features/sellers/public-seller-screen.tsx`; check `features/search/panes/CategoriesSearchPane.tsx` and the discovery screens). A consumer that is not a work-card grid stays as it is and is listed in the report.
3. **Check mark.** `FilterOptionRow`: draw the check with `FigmaIcon` (`check`; if the glyph is missing STOP and report) instead of a rotated bordered box; replace the screen-name `variant` branches with a role prop or data coming from the caller. Keep the visible result at 390 identical; if it is not identical say so.
4. **`WorkGallery`:** update the active index on `onMomentumScrollEnd` (and on programmatic scroll), not with `setState` on every `onScroll`. Keep the dots/index behavior.

## Boundaries

- `AuthConsentCheckbox` and the gradient-border mechanisms are **not** touched (no bug, separate backlog).
- No `@rn-primitives/*` or other new dependency. If a local Tabs cannot meet the keyboard/a11y requirements, STOP and ask.
- Screens are not re-laid-out; the 390 design stays as it is, except tabs follow the two Figma patterns above.
- Native paths are compiled but not claimed.

- `rg -n "rotate\('-45deg'\)" apps/mobile/src` -> empty.

- Typecheck, lint, vitest green. Playwright chromium: `tab-switch-reveal`, `catalog-pagination`, `author-static-header`, `search-overlay`, `creator-profile` (or "not run: reason").

## Stop

Tabs need a primitive to pass keyboard a11y; the `check` glyph is missing; a grid consumer cannot be expressed as `minCard`/`gap`/`max` without a new prop type.
