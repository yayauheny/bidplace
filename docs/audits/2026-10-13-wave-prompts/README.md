# Промты волн оптимизации дизайн-системы

План и обоснование — в `../2026-10-13-FRONTEND-DESIGN-SYSTEM-AUDIT.md` (§17–§18). Здесь — готовые промты для Codex. Промты написаны по-английски (так исполнитель следует им надёжнее), инструкция — по-русски.

Один промт = `_common.md` (контракт исполнителя) + файл волны. Исполнитель **не видит аудит** (он лежит вне его worktree), поэтому всё нужное внутри промта.

## Подготовка (один раз; можно поручить координатору)

```sh
git -C ~/projects/bidplace tag pen-v2-pre-removal f4c37a8e          # локальный, не пушить
git -C ~/projects/bidplace worktree add -b ds/w0-pen ~/projects/bidplace-ds f4c37a8e
cd ~/projects/bidplace-ds && pnpm install
```

`~/projects/bidplace` (рабочая копия) устарела; все волны идут от `f4c37a8e` в `~/projects/bidplace-ds`. `~/projects/bidplace-home-figma-completion` — только чтение.

## Запуск волны

```sh
P=~/projects/bidplace/docs/audits/2026-10-13-wave-prompts
cat $P/_common.md $P/W0.md | codex exec -C ~/projects/bidplace-ds -m gpt-5.6-terra \
  -c model_reasoning_effort="medium" -s workspace-write -
```

Для остальных волн меняются файл, `-m` и effort по таблице. Последний ответ Codex — отчёт по формату из `_common.md`; сохраните его и передайте координатору.

Заметки по песочнице: `workspace-write` не даёт сеть и запись в `.git` вне worktree, поэтому исполнитель **ничего не коммитит** (контракт п. 8) и честно пишет «not run» для Playwright, если ему не поднять Postgres/web (`apps/mobile/e2e/README.md`). Если хотите, чтобы e2e гонял исполнитель, это отдельное осознанное решение (`-s danger-full-access`).

## Приёмка и переход к следующей волне (делает координатор)

1. Принести отчёт. Координатор читает `git diff`, сверяет с «Done when» **grep-ом**, сам перезапускает `typecheck`, `lint`, узкие vitest; сверяет числа с живым Figma.
2. Принято → координатор коммитит короткими сообщениями без упоминания агентов в ветке волны и создаёт следующую ветку: `git -C ~/projects/bidplace-ds switch -c ds/w1-sheet`. Один draft-PR на волну, цепочка веток `ds/w0-pen → ds/w1-sheet → …`; в remote ничего не пушится без вашего слова.
3. Не принято → один короткий бриф с точечными правками. Два провала по одной причине → координатор сам ищет корень (эскалация на sol `medium` только точечно).
4. Перед запуском каждой следующей волны координатор перечитывает её промт против фактического кода после предыдущей (имена и пути — по символам; номера строк в промтах — подсказки).
