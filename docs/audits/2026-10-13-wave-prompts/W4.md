# WAVE W4 — Hygiene deletions

Model: luna, effort medium. Base: the accepted result of W3 (branch `ds/w4-hygiene`). Small, mechanical. No visual change is intended.

## Why

Small leftovers cost attention on every future task: a second icon library imported for one glyph, a "destructive" button that is visually identical to the primary one, a private import path of the router, a dev-only route in the production bundle, and a hand-written reduced-motion hook.

## Do

1. **Remove `lucide-react-native`.** `apps/mobile/src/components/ui/AppIcon.tsx` is its only consumer (two call sites). Replace both with `FigmaIcon` using the equivalent close glyph (check that `FigmaIcon` has one; if it does not, STOP and report). Delete `AppIcon.tsx`, remove the dependency from `apps/mobile/package.json` and update `pnpm-lock.yaml` with `pnpm install --lockfile-only` (offline allowed); if the lockfile cannot be updated without network, leave the lockfile and say so in the report. Compare the glyph size/weight to the replaced one and report any visible difference.
2. **Remove `DestructiveButton`.** It is currently rendered like a primary button. Replace its ~9 usages (4 files; `rg -n "DestructiveButton" apps/mobile/src`) with `PrimaryButton`, delete the component from `components/ui/Button.tsx` and its line in `components/README.md`.
3. **Public router import.** `usePreventRemove` is imported from `expo-router/build/...` in `layout/AuthViewport.tsx` and `features/sellers/product-draft-screen.tsx`. First confirm the symbol is exported from the public entry `expo-router/react-navigation` in the installed version (check `node_modules/expo-router`); then switch both imports. If it is not exported publicly, STOP and report.
4. **Dev route in production.** `apps/mobile/src/app/(public)/dev/figma-buttons.tsx` is reachable in a production export. Make it unreachable in the production web bundle while the Playwright spec `figma-button-matrix.spec.ts` keeps working. Look at how the e2e web server is started (`apps/mobile/playwright*.config.ts`, `e2e/prepare.mjs`) and use whatever environment signal it already sets. If it cannot be done without introducing a new environment variable or flag, STOP and report the options instead of adding one.
5. **Reduced motion (optional, only if trivial).** `apps/mobile/src/lib/reduced-motion.ts` is a hand-written hook (about 5 consumers and their specs). Replace it with Reanimated's `useReducedMotion` only if every consumer and spec stays green and the web behavior (`matchMedia`) is demonstrated by an existing or updated unit test. Otherwise skip it and write why in the report.

## Boundaries

- Nothing beyond this list. No visual restyling. No new dependency; one removed.
- Do not refactor `AuthViewport` or `product-draft-screen` beyond the import line.

## Done when

- `rg -n "lucide|AppIcon|expo-router/build|DestructiveButton" apps packages --glob '!pnpm-lock.yaml'` -> empty.
- `git diff -- pnpm-lock.yaml` shows only removal of `lucide-react-native` (or the report says the lockfile was not updated and why).
- Typecheck, lint, vitest green; Playwright chromium `figma-button-matrix` (or "not run: reason").
- A production web export does not contain the `/dev/figma-buttons` route: run `pnpm --filter @bidplace/mobile exec expo export --platform web --output-dir /tmp/w4-export` and show the route list / `rg` of the output (or "not run: reason").
- Code `git diff --shortstat`: deletions >= additions.

## Stop

`FigmaIcon` has no close glyph; `usePreventRemove` is not public; gating the dev route needs a new flag.
