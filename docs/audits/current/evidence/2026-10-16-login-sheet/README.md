## W11-01 — zoom, скролл-доступность, клавиатура

- **CSS zoom** переименован в пробе в `css-zoom-reflow` (`style.zoom = '2'`):
  это не browser zoom. Проверяется: нет горизонтального overflow на уровне
  страницы, «Войти» остаётся в вьюпорте.
- **Реальный browser zoom (Ctrl/⌘ +)**: Playwright/Chromium CDP не эмулирует
  десктопный zoom страницы (page scale factor — это pinch-zoom без reflow;
  device metrics — DPI, не zoom). Статус: **Needs verification**, ручная
  инструкция: открыть `expo start --web`, на `/login` нажать Ctrl/⌘ «+» до
  200%, убедиться, что шторка рефлоится без горизонтальной прокрутки и
  «Войти» reachable; записать движок и масштаб.
- **Увеличение текста** (настройка размера шрифта браузера): автоматической
  эмуляции нет. Статус: **Needs verification**, ручная инструкция: в
  настройках Chromium «Очень крупный» шрифт, повторить те же наблюдения.
- **Скролл-доступность на короткой области** (390×400): у шторки есть
  scroll-owner (`scrollHeight > clientHeight`); email, пароль, «Войти»,
  «Войти с Google» и обе legal-ссылки достижимы прокруткой — каждая цель
  `scrollIntoViewIfNeeded` → `toBeInViewport` + `toBeVisible`. Проверено в
  обоих движках.
- **Клавиатурный обход**: Tab достигает каждого интерактивного контрола
  шторки в DOM-порядке (включая обе legal-ссылки), Shift+Tab идёт обратно
  (двусторонняя проверка; начальная парковка фокуса на контейнере Radix
  обходится walk-forward с капом, asserts не ослаблены). Проверено в обоих
  движках.
